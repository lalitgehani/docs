---
title: "useQuery Hook"
description: "List records with React state"
---

`useQuery` loads a collection list with loading/error state. It supports the classic `RecordListParams` form and a QueryBuilder factory form.

## Import

```ts
import { useQuery } from "@snackbase/react";
```

## Params form (backward compatible)

```tsx
function PostList() {
  const { data, loading, error, refetch } = useQuery("posts", {
    limit: 20,
    sort: "-created_at",
  });

  if (loading) return <p>Loading...</p>;
  if (error) return <p>{error.message}</p>;

  return (
    <ul>
      {data?.items.map((post: any) => (
        <li key={post.id}>{post.title}</li>
      ))}
      <button onClick={() => refetch()}>Refresh</button>
    </ul>
  );
}
```

## QueryBuilder form

```tsx
function FilteredPosts() {
  const { data, loading } = useQuery("posts", (qb) =>
    qb.filter('status = "published"').sort("-created_at").limit(10)
  );

  if (loading) return null;
  return <pre>{JSON.stringify(data?.items, null, 2)}</pre>;
}
```

## Options

```ts
useQuery(collection, paramsOrBuilder?, options?: {
  enabled?: boolean;              // default true; when false, skip fetch
  listenToInvalidation?: boolean; // default true — refetch when mutations invalidate this collection
})
```

```tsx
// Conditional fetch
const { data } = useQuery("posts", { limit: 10 }, { enabled: Boolean(userId) });
```

## Invalidation

When `useMutation(collection, { invalidateOnSuccess: true })` succeeds, mounted `useQuery` / `useRecord` for the same collection refetch (if `listenToInvalidation` is not false). **Default for mutations is `invalidateOnSuccess: false`.**

## Stale responses

If params change mid-flight, older responses are ignored so they cannot overwrite newer data.
