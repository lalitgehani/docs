`@snackbase/react` provides React hooks and a context provider for SnackBase apps. It is a thin binding over `@snackbase/sdk` (React state/effects only; all I/O goes through the injected client).

## Installation

```bash npm
npm install @snackbase/react @snackbase/sdk react
```

```bash yarn
yarn add @snackbase/react @snackbase/sdk react
```

```bash pnpm
pnpm add @snackbase/react @snackbase/sdk react
```

<Note>
  React 18 or higher is required (`peerDependencies`: `react` / `react-dom` `>=18`).
</Note>

## Setup

### Client form (recommended)

Construct a `SnackBaseClient` once and pass it to the provider:

```tsx
import { SnackBaseClient } from "@snackbase/sdk";
import { SnackBaseProvider } from "@snackbase/react";

const client = new SnackBaseClient({
  baseUrl: "https://api.example.com",
  // apiKey, storageBackend, enableLogging, ...
});

function App() {
  return (
    <SnackBaseProvider client={client}>
      <YourApp />
    </SnackBaseProvider>
  );
}
```

### Config form

Pass `baseUrl` (and other `SnackBaseConfig` fields) and the provider constructs a stable client when config is unchanged:

```tsx
import { SnackBaseProvider } from "@snackbase/react";

function App() {
  return (
    <SnackBaseProvider baseUrl="https://api.example.com">
      <YourApp />
    </SnackBaseProvider>
  );
}
```

### Use hooks

```tsx
import { useAuth, useRecord } from "@snackbase/react";

function Profile() {
  const { user, login, logout, expiresAt } = useAuth();
  const { data: profile, loading } = useRecord("profiles", user?.id ?? "");

  if (!user) {
    return (
      <button onClick={() => login({ email: "a@b.com", password: "secret" })}>
        Login
      </button>
    );
  }

  return (
    <div>
      <h1>Welcome, {user.email}</h1>
      <p>Session expires: {expiresAt}</p>
      {loading ? <p>Loading...</p> : <pre>{JSON.stringify(profile, null, 2)}</pre>}
      <button onClick={() => logout()}>Logout</button>
    </div>
  );
}
```

## Provider props

| Form | Props | Description |
| ---- | ----- | ----------- |
| Client | `client: SnackBase`, `children` | Pre-built client (full control) |
| Config | `baseUrl` + optional `SnackBaseConfig` fields, `children` | Provider constructs `SnackBaseClient` |

## Hooks overview

| Hook | Purpose |
| ---- | ------- |
| `useAuth` | Auth state + app auth actions |
| `useQuery` | List records (`RecordListParams` or QueryBuilder) |
| `useRecord` | Single record by id |
| `useMutation` | create/update/patch/delete/batch/aggregate |
| `useSubscription` | Realtime collection events |
| `useRealtime` | Connection status / connect / disconnect |
| `useFiles` | Upload, download URL, delete |
| `useInvitation` | Public invite get + accept |
| `useClientAction` | Generic loading/error wrapper for any async call |
| `useSnackBase` | Escape hatch to the raw client |

## Intentional non-wrappers (admin domains)

These SDK services have **no** dedicated React hooks. Use the escape hatch:

```tsx
import { useSnackBase, useClientAction } from "@snackbase/react";

function AdminJobs() {
  const client = useSnackBase();
  const { run, loading, error } = useClientAction(() => client.jobs.list());

  // Also available: admin, migrations, webhooks, hooks, endpoints, workflows,
  // macros, collectionRules, auditLogs, dashboard, emailTemplates,
  // collections (schema CRUD), accounts, users, groups, apiKeys, roles
  return (
    <button disabled={loading} onClick={() => run()}>
      Load jobs
    </button>
  );
}
```

## With Vite

```tsx
// src/main.tsx
import React from "react";
import ReactDOM from "react-dom/client";
import { SnackBaseClient } from "@snackbase/sdk";
import { SnackBaseProvider } from "@snackbase/react";
import App from "./App";

const client = new SnackBaseClient({
  baseUrl: import.meta.env.VITE_SNACKBASE_URL,
});

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <SnackBaseProvider client={client}>
      <App />
    </SnackBaseProvider>
  </React.StrictMode>
);
```

## With Next.js (App Router)

```tsx
// app/providers.tsx
"use client";

import { SnackBaseClient } from "@snackbase/sdk";
import { SnackBaseProvider } from "@snackbase/react";

const client = new SnackBaseClient({
  baseUrl: process.env.NEXT_PUBLIC_SNACKBASE_URL!,
});

export function Providers({ children }: { children: React.ReactNode }) {
  return <SnackBaseProvider client={client}>{children}</SnackBaseProvider>;
}
```

## Security note

`useAuth` exposes `token` and `refreshToken` for advanced integrations. **Do not render tokens in the UI or log them.** OAuth/SAML helpers only pass through the SDK; the React layer does not add custom token storage.

## TypeScript

App-facing types can be imported from `@snackbase/react` or `@snackbase/sdk`:

```tsx
import { useAuth, useRecord, type User, type AuthState } from "@snackbase/react";
```
