---
title: "useMutation Hook"
description: "Create, update, patch, delete, batch, and aggregate in React"
---

## Import

```ts
import { useMutation } from "@snackbase/react";
```

## Usage

```tsx
function CreatePost() {
  const { create, patch, del, batchCreate, aggregate, loading, error } =
    useMutation("posts");

  return (
    <button
      disabled={loading}
      onClick={async () => {
        try {
          await create({ title: "Hello" });
        } catch {
          // error is set and rethrown
        }
      }}
    >
      Create
    </button>
  );
}
```

## API

| Method | SDK |
| ------ | --- |
| `create(data)` | `records.create` |
| `update(id, data)` | `records.update` (full PUT) |
| `patch(id, data)` | `records.patch` |
| `del(id)` | `records.delete` |
| `batchCreate(records)` | `records.batchCreate` |
| `batchUpdate(items)` | `records.batchUpdate` |
| `batchDelete(ids)` | `records.batchDelete` |
| `aggregate(params)` | `records.aggregate` |

Shared `loading` / `error` across concurrent calls (last completion clears loading). Errors are set on `error` **and rethrown**.

## Optional invalidation

```tsx
const { create } = useMutation("posts", { invalidateOnSuccess: true });
// After success, mounted useQuery/useRecord for "posts" refetch
```

Default is `invalidateOnSuccess: false` so existing apps are not surprised by extra network calls.
