---
title: "useAuth Hook"
description: "Authentication state and actions in React"
---

The `useAuth` hook syncs full auth state from the SDK (including `expiresAt`) and exposes app-facing auth actions with a shared `isLoading` flag.

## Import

```ts
import { useAuth } from "@snackbase/react";
```

## Usage

```tsx
function Profile() {
  const {
    user,
    account,
    expiresAt,
    login,
    logout,
    register,
    isLoading,
    error,
    isAuthenticated,
  } = useAuth();

  if (isLoading) return <div>Loading...</div>;
  if (!user) {
    return (
      <button onClick={() => login({ email: "a@b.com", password: "secret" })}>
        Login
      </button>
    );
  }

  return (
    <div>
      <h1>Welcome, {user.email}</h1>
      <p>Account: {account?.name}</p>
      <p>Expires: {expiresAt}</p>
      {error && <p>{error.message}</p>}
      <button onClick={() => logout()}>Logout</button>
    </div>
  );
}
```

## Return value (selected fields)

| Field / method | Description |
| -------------- | ----------- |
| `user`, `account`, `token`, `refreshToken` | Auth state from SDK (`refreshToken` is the **token string**, not an action) |
| `expiresAt` | ISO expiry from AuthManager — not hard-coded null |
| `isAuthenticated`, `tokenType` | Session flags |
| `isSuperadmin`, `isApiKeySession`, `isPersonalTokenSession`, `isOAuthSession` | Derived from client |
| `login`, `logout`, `register`, `forgotPassword`, `resetPassword` | Core email/password |
| `refreshAccessToken` | Calls `client.refreshToken()` (named to avoid clashing with the `refreshToken` string field) |
| `getCurrentUser`, `verifyEmail`, `resendVerificationEmail`, `sendVerification`, `verifyResetToken` | Verification helpers |
| `getOAuthUrl`, `handleOAuthCallback` | OAuth |
| `getSAMLUrl`, `handleSAMLCallback`, `getSAMLMetadata` | SAML |
| `isLoading` | Shared loading flag for concurrent auth actions |
| `error` | Last `auth:error` or action failure; cleared on successful login/refresh |

## Events

The hook subscribes to `auth:login`, `auth:refresh`, `auth:logout`, and `auth:error`, and unsubscribes on unmount.

## OAuth example

```tsx
function OAuthLogin() {
  const { getOAuthUrl, handleOAuthCallback, isLoading } = useAuth();

  const startGoogle = async () => {
    const { authorization_url } = await getOAuthUrl(
      "google",
      window.location.origin + "/auth/callback"
    );
    window.location.href = authorization_url;
  };

  // On callback route, call handleOAuthCallback({ provider, code, redirectUri, state })
  return (
    <button disabled={isLoading} onClick={startGoogle}>
      Continue with Google
    </button>
  );
}
```

## Security

Do not log or render `token` / `refreshToken`. Treat them as secrets.
